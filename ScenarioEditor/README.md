# シナリオエディタ

彦根・京橋の地図の上で、カスタム場面（`../Scenarios/*.json`）を作るブラウザ用エディタです。

## 起動

```sh
cd ScenarioEditor
node server.mjs
```

ブラウザで http://localhost:8765/ を開きます（Node.js 20 以上。インストールするパッケージはありません）。

## できること

- 地図上で **出発点・ゴール・トリガー** をドラッグで配置（□ で大きさ、○ で向き）
- **車のルートを描く**：「✎ 車を描く」→ クリックで点を追加 → Enter / ダブルクリックで完了。組み込みの車線に 3 m 以内なら吸着（Alt で解除）
- 「組み込みの車線から追加」で、組み込み 10 場面の車線をそのまま使う
- 車ごとに：車種・速さ・出発の基準（開始から / トリガーに入ってから）・待ち時間・繰り返し（車の流れ）・事故車
- **タイムライン**：▶ で車の動きを再生。トリガーに入る時刻は歩く速さ（1.2 m/s、自転車 4 m/s）から推定
- **事故車と体験者の線が交わる時刻**を表示（「車は X 秒 早い / 遅い」）
- **チェック**：Unity と同じ形式チェック＋地図チェック（道路の外、堀の上、見えない壁など）。クリックで該当箇所へ
- **保存**：`Scenarios/<id>.json`。ひな形（`templates/`）は上書きせず、別の id で保存
- **▶ Unityで試す**：保存して、開いている Unity エディタで再生（`Scenarios/.play-request.json` 経由）
- **⇪ Questに送る**：エラーのない「マイ場面」を、USB（またはワイヤレス adb）でつないだ Quest のアプリにコピー。PC で消した場面は Quest からも消えます。Quest ではタイトル画面の「カスタム」タブ →「読み直す」
- 元に戻す / やり直す（Ctrl+Z / Ctrl+Shift+Z）、Ctrl+S で保存

URL で表示を指定できます：`?open=templates/builtin-01.json&select=vehicle:2&time=12&layers=surfaces`

## テスト

```sh
npm test
```

## 構成

| ファイル | 内容 |
| --- | --- |
| `server.mjs` | 画面・地図・場面ファイルを配信し、保存・削除・Unity 再生依頼を受ける（127.0.0.1 のみ） |
| `web/scenario.js` | データ形式・保存形式・チェック・タイミング計算（ブラウザ・サーバ・テストで共用）。Unity の `CustomScenario.cs` と同じ内容に保つ |
| `web/app.js` | 画面の操作 |
| `test/` | `node --test` のテスト（`fake-adb.mjs` は Quest の代わり） |

## Quest に送るときの準備

- Quest を開発者モードにして、アプリ（VRLearn）をインストール済みであること
- USB でつなぎ、ヘッドセットで「USB デバッグを許可」を選ぶ（ワイヤレス adb でも可）
- adb は自動で探します（Unity の Android サポートに含まれる adb でも可）。見つからないときは環境変数 `ADB` にパスを指定
